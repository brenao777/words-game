# СЛОВОКРУГ — дизайн-концепция

Браузерная игра-кроссворд «собери слово из колеса букв» (механика Wordscapes / Words of Wonders), полностью офлайн, mobile-first.

## Концепция: «Ночное золото»

Минимализм на тёмном фоне с одним тёплым акцентом. Никакого визуального шума:
игрок видит только сетку, колесо и своё слово. Всё остальное — тонкие линии и воздух.

### Палитра

| Роль | Цвет |
|---|---|
| Фон | глубокий чернильно-синий `#10141f`, радиальный градиент к `#181e30`, мягкое «дыхание» свечения за колесом |
| Открытая плитка | слоновая кость `#f5f0e4`, буква — чернильная `#1c2233` |
| Пустая ячейка | стеклянная: `rgba(255,255,255,.05)` + тонкая обводка |
| Акцент (один!) | тёплое золото `#f2b64b` — линия колеса, монеты, успех, подсказки |
| Текст вторичный | серо-голубой `#8b93ad` |

### Типографика

Системный гротеск (SF / Roboto / Segoe), буквы — верхний регистр, вес 700,
лёгкий letter-spacing. Никаких подключаемых шрифтов — офлайн и скорость.

### Композиция (портрет, одна рука)

- Верх: тонкая панель — назад, номер уровня, прогресс найденных слов, монеты, звук.
- Центр: сетка кроссворда (≤7 колонок), ячейки масштабируются под уровень.
- Над колесом: превью собираемого слова — плитки появляются по одной.
- Низ (~40% экрана, зона большого пальца): колесо букв, в центре — «перемешать»,
  по бокам — две круглые кнопки подсказок.
- Ни скролла, ни зума нигде: `100dvh`, `touch-action:none`, фиксированная сетка уровней 5×10.

### Движение

Всё пружинит (`cubic-bezier(.34,1.56,.64,1)`):

- буква захвачена — увеличивается и вспыхивает золотом, за пальцем тянется светящаяся линия;
- слово угадано — плитки каскадно переворачиваются с интервалом 45 мс;
- неверное слово — мягкий shake превью и рассыпание;
- бонусное слово — монета летит по дуге в счётчик;
- уровень пройден — золотая радиальная волна + оверлей со статистикой.

### Звук (Web Audio, полностью синтез)

Тёплый, тихий, «деревянный» тембр; общий компрессор, никаких резких атак:

- выбор буквы — короткий щипок (треугольная волна + lowpass), каждая следующая
  буква — ступень вверх по пентатонике (слово «поётся»);
- отмена буквы — та же нота ступенью вниз;
- слово угадано — быстрое арпеджио + мягкое мерцание октавой выше;
- бонус — «монетка»: синусоидальное глиссандо вверх + искра из фильтрованного шума;
- ошибка — глухой низкий тук с падением частоты;
- уровень пройден — мини-фанфара из трёх аккордов.

Плюс лёгкая вибрация (`navigator.vibrate`) на захват буквы и успех, где поддерживается.

## Экономика

- старт: 100 монет;
- слово из сетки: +3;
- бонусное слово (есть в словаре, но не в сетке): +5;
- уровень пройден: +20;
- подсказка «лампа» (случайная буква): 25;
- подсказка «мишень» (буква в выбранной ячейке): 50.

## Уровни

50 уровней, все открыты сразу. Сложность растёт: 5 букв / 4 слова → 7 букв / 9 слов.
Сетка не шире 7 колонок и не выше 8 строк. Уровни генерируются заранее
(`tools/generate.js`) из словаря общеизвестных существительных
(им. падеж, ед. число, «ё»→«е») и валидируются:

- каждое слово собирается из букв колеса (мультимножество);
- все слова связаны в одну фигуру, пересечения согласованы;
- в сетке нет случайных «не-слов» (каждая непрерывная цепочка ≥2 букв — слово уровня);
- ширина ≤7, высота ≤8, дубликатов нет.
- трёхбуквенное слово встречается не более трёх раз за игру, остальные —
  не более двух, с интервалом минимум восемь уровней.

## Архитектура

Ванильный JS без сборки и зависимостей, обычные `<script>` — работает даже с `file://`.

```
index.html
css/style.css
js/audio.js        — синтезатор звуков (Web Audio)
js/storage.js      — прогресс в localStorage
js/wheel.js        — колесо букв (pointer events + SVG-линия)
js/game.js         — игровой экран: сетка, проверка слов, подсказки
js/app.js          — экраны, выбор уровня
js/levels.data.js  — 50 уровней (генерируется)
js/dictionary.js   — словарь бонусных слов (генерируется)
tools/dictionary.ru.js — исходный словарь
tools/generate.js  — генератор + валидатор уровней
tools/build.js     — сборка одностраничного dist/slovokrug.html
```
