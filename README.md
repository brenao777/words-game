# Словокруг

Браузерная игра-кроссворд на русском: внизу — колесо букв, игрок ведёт пальцем
и собирает слова; угаданные слова открываются в кроссворде сверху. Слова,
которых нет в сетке, но которые есть в словаре, приносят монеты — монеты
тратятся на подсказки.

- 50 уровней растущей сложности, все доступны сразу
- Mobile-first, портрет, играется одной рукой, без скролла и зума
- Полностью офлайн: без бэкенда и внешних ресурсов, прогресс в `localStorage`
- Все звуки синтезируются кодом через Web Audio

Концепция дизайна — в [DESIGN.md](DESIGN.md).

## Запуск

Никакой сборки не нужно:

```bash
# любой статический сервер, например:
python3 -m http.server 8000
# → http://localhost:8000
```

или просто откройте `index.html` (работает и с `file://`),
или один автономный файл `dist/slovokrug.html` — его можно отправить на телефон
как есть.

## Инструменты

```bash
node tools/generate.js   # перегенерировать 50 уровней из словаря + валидация
node tools/build.js      # собрать одностраничный dist/slovokrug.html
npm test                # запустить автоматические тесты
```

Словарь — `tools/dictionary.ru.js` (общеизвестные существительные,
им. падеж, ед. число, «ё» → «е»). Генератор детерминирован (фиксированный seed)
и проверяет каждый уровень: сборка каждого слова из букв колеса, связность
фигуры, согласованность пересечений, отсутствие случайных «не-слов» в сетке,
ширина ≤ 7, высота ≤ 8.

## Структура

```
index.html          — разметка
css/style.css       — стили («Ночное золото»)
js/audio.js         — синтез звука (Web Audio)
js/storage.js       — прогресс в localStorage
js/wheel.js         — колесо букв (pointer events + SVG-линия)
js/game.js          — сетка, проверка слов, бонусы, подсказки
js/app.js           — экраны и навигация
js/levels.data.js   — 50 уровней (сгенерировано)
js/dictionary.js    — словарь бонусных слов (сгенерировано)
tools/              — словарь, генератор, сборщик
```
